# OpenPonk: Markov Chains

[![Nightly](https://github.com/OpenPonk/markov-chains/actions/workflows/nightly.yml/badge.svg)](https://github.com/OpenPonk/markov-chains/actions/workflows/nightly.yml) [![Coverage Status](https://coveralls.io/repos/github/OpenPonk/markov-chains/badge.svg?branch=master)](https://coveralls.io/github/OpenPonk/markov-chains?branch=master)

Markov Chains diagram editor, simulator, and solver integration for the [OpenPonk](https://openponk.org) modeling platform.

## Download

Download pre-built portable archives from [Releases](https://github.com/OpenPonk/markov-chains/releases), or get the all-in-one build at [openponk.org/#download](https://openponk.org/#download).

## Installation

See [openponk.org/#direct-installation](https://openponk.org/#direct-installation) for the supported Pharo version.

```smalltalk
Metacello new
	baseline: 'OpenPonkMarkovChains';
	repository: 'github://OpenPonk/markov-chains';
	load.
```
